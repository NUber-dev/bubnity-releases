# Bubnity downloads

Installers and updates for Bubnity, voice dictation for Mac and Windows. No source code here.

- **Windows:** open the newest `windows-v…` release and download `BubnityApp-win-Setup.exe`. Installed copies update themselves.
- **Mac:** open the newest `mac-v…` release and download the `.zip`.

All versions: [Releases](../../releases).
